# The shape of a rules file, and one filled in

## The shape

```markdown
# How I work

## Writing
- [how the output should read, in their words]
- [words or shapes they never want]
- [length, and what happens when it needs to be longer]

## My tools and names
- [the program they actually use for a job]
- [what they call their own projects, folders, clients]

## Never without asking
- [the irreversible things]

## What finished means
- [the check a piece of work passes before it is called done]
```

Use only the headings that earned their place. A section with one line under it is better folded into another.

## A filled-in example

This is a real shape rather than a good set of rules to copy. The value is in how specific each line is, not in the rules themselves.

```markdown
# How I work

## Writing
- Answer first, reasoning after. I read the first 2 lines and decide whether to read the rest.
- Never open with "Certainly", "Great question", or "I'd be happy to".
- Under 200 words unless I ask for the long version.
- British spelling.

## My tools and names
- Spreadsheets are Google Sheets, never Excel.
- "The deck" means the client pitch template in /presentations, not any other file.
- Clients are referred to by first name only in anything I might share.

## Never without asking
- Do not delete or overwrite a file I did not name.
- Do not send, post or publish anything, ever. Draft it and stop.
- Do not install anything.

## What finished means
- If you changed something that runs, run it and show me the output.
- Tell me what you did not check.
```

## Why each of those lines exists

Worth understanding before writing someone else's, because the pattern is what transfers.

- **"I read the first 2 lines and decide"** gives the reason, so Claude can apply the rule to a format nobody anticipated. A bare "answer first" cannot stretch that far.
- **The named opening phrases** are specific enough to be checkable. "Do not be sycophantic" is not.
- **"The deck" means one file** removes a guess that would otherwise cost a correction every week.
- **"Draft it and stop"** states the alternative. A prohibition on its own leaves Claude improvising.
- **"Tell me what you did not check"** is the line that changes the most, because it converts a confident summary into an honest one.
